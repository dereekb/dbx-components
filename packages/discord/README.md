@dereekb/discord
=======

Framework-agnostic Discord OAuth 2.0 client. Carries no `discord.js` dependency and no bot-token
requirement, so it can be used from a server that only performs the per-user authorization-code
handoff. For the bot/webhook gateway integration see `@dereekb/nestjs/discord`.

The sources for this package are in the main [@dereekb/dbx-components](https://github.com/dereekb/dbx-components) repo. Please file issues and pull requests against that repo.
